# معاذ السلمي · ATELIER 09

بورتفوليو عربي وإنجليزي يعرض أعمال معاذ السلمي في تطوير الويب وتكامل Flask ومراقبة الأنظمة. تبدأ الأعمال المختارة بمشروع التخرج Numoo وتدريب المركز الوطني للأرصاد ومشروع Git × Pathy. يعرض الأطلس التجارب والأبحاث حسب مرحلتها.

## التشغيل المحلي

من مجلد المشروع، شغّل الأمر التالي باستخدام Python 3.

```sh
python -m http.server 8766 --bind 127.0.0.1
```

افتح [الصفحة المحلية](http://127.0.0.1:8766/). على ويندوز يمكن استخدام `py` بدل `python` عند الحاجة.

- عدّل المحتوى الثابت وترتيب الأقسام في `index.html`.
- حدّث ترجمات المشاريع والمهارات ودراسات الحالة في `app.js`.
- عدّل مشاهد الواجهة والبحث ومحاكاة المختبر في `atelier.js`.
- حدّث الملخص المهني القابل للطباعة في `professional-summary.html`.
- اختبر العربية والإنجليزية والمظهرين بعد تعديل المحتوى، وراجع حالات المشاريع وروابط الأدلة.

## التوزيع والنشر

```sh
python build.py --pages _site
python build.py
```

الأمر الأول ينسخ ملفات الموقع إلى مجلد نشر فارغ. الثاني يولّد نسخة HTML مستقلة للمعاينة تُحفظ في `dist/` وتتضمن الخطوط والصور. تحتاج روابط الأدلة الخارجية إلى اتصال بالشبكة. يوضح [ملف التسليم](HANDOFF_TO_SOL.md) إعداد GitHub Pages والتحقق من الرابط العام والرجوع إلى إصدار سابق.
